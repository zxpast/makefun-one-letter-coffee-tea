One letter: **A — coffee**. The fuller, more alive answer in the coffee-against-tea argument: the drink that fuels the builders.

## Run it

```sh
mkdir -p out && OUTPUT_DIR=out node main.ts
```

`main.ts` writes exactly one byte, `A`, with no trailing newline, to `/output/entry.txt` (or `$OUTPUT_DIR/entry.txt` for local runs). Node 22 standard library only, fully deterministic: no clock, no randomness, no network, no input files — the same single byte on every run.
